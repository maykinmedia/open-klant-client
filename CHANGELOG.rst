=========
Changelog
=========

0.6.0 (2026-08-13)
==================

* Add 'hadBetrokkene__wasPartij__uuid' filter for the 'KlantContact' resource.
* Add 'klantcontact__uuid' filter for the 'Onderwerpobjectidentificator' resource.

0.5.0 (2025-07-30)
==================

* Add 'referentie' attribute for the 'DigitaalAdres' resource.
* Updated supported Open Klant version to 2.17.1.

0.4.0 (2025-12-19)
==================

* Add 'partial_update' method for the 'DigitaalAdres' resource.
* Add more query params for the 'DigitaalAdres' resource.

0.3.0 (2025-12-05)
==================

* Add 'methods' namespace for convenience methods.
* Add 'maak-klant-contact' convenience method.

0.2.0 (2025-11-12)
==================

* Make 'token' parameter optional for the client initialization.
* Add more query params for the 'DigitaalAdres' resource.

0.1.0 (2025-10-06)
==================

Extacted the code from Open Inwoner and published it on PyPI under 'open-klant-client'.
